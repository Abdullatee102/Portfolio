# Abdullateef Opeyemi — Developer Portfolio

A responsive developer portfolio web application built with React and Vite to showcase cross-platform mobile applications, responsive web interfaces, scalable backend APIs, and decentralized blockchain protocols.

* **Frontend & Web:** React 19, JavaScript (ES6+), HTML5, CSS3, Custom CSS Variables

* **Blockchain & Web3:** Solidity, Foundry, Wagmi, Viem, Ethers.js, Reown AppKit, Sepolia Testnet

* **Deployment & Hosting:** Vercel, Render

## 🚀 Featured Projects

### 1. Blockchain / Web3 Development
* **CircleFlow:** Non-custodial, blockchain-based rotating savings protocol (ROSCA / Ajo / Esusu) on Ethereum Sepolia featuring dynamic security reserve collateral, automated default resolution, and zero centralized backend dependencies.
* **On-Chain Certificate Issuer:** Decentralized Soulbound (non-transferable) ERC-721 academic credentialing platform with 100% on-chain SVG generation (`tokenURI`), role-based issuer authorization, and instant public verification.
* **StudentPay Escrow:** Peer-to-peer crypto escrow application on BotChain Mainnet engineered for students to securely transact for services, freelance tasks, and merchandise with trustless smart contract guarantees.

### 2. Mobile Development
* **BrainBuzz (Quiz App):** Academic assessment and quiz application providing timed Computer-Based Test (CBT) practice, interactive answering interfaces, persistent progress tracking, and notifications.
* **LearningApp (E-learning):** Mobile learning platform featuring dynamic book cataloging, reading progress tracking, and community discussion boards backed by Supabase with Row Level Security.
* **FitCount (Fitness Tracker):** Mobile activity tracker designed to log daily physical metrics, monitor workout routines, and securely manage user profiles via Firebase Authentication.

### 3. Backend Development
* **QuizBackend:** High-performance RESTful API and WebSocket backend powering the BrainBuzz mobile assessment platform and companion web applications. Built with Express 5, TypeScript, Drizzle ORM, PostgreSQL (Neon Serverless), and Socket.IO.

### 4. Web Development
* **Crypto Tracker:** Real-time cryptocurrency price monitoring tool tracking live market values, 24-hour volume changes, and token statistics fetched via external APIs.
* **Advanced Calculator:** Responsive functional utility application handling standard and advanced mathematical operations with clean grid layouts.
* **Interactive Clock & Timer:** Timekeeping application featuring live local time tracking, countdown timers, and stopwatches built with clean CSS styling.

## 🚦 Getting Started Locally

To run this portfolio on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Abdullatee102/My_Portfolio.git
   cd My_Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
